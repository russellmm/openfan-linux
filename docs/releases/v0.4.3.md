# OpenFan Linux v0.4.3

November 14, 2026

All ASUS WRX90 BMC fan controls now accept **0–100% PWM**. Version 0.4.2 imposed
software limits that were not established hardware limits: a 20% minimum on CPU/chassis
headers, a fixed 100% pump-header target, and a 70°C override. This release removes them.
Manual targets apply the requested duty to all five BMC curve points; OpenFan's user-assigned
curves determine fan speed.

Calibration sliders for these controls start at **0%**, and automatic sweeps include
**0%, 10%, 20%, …, 100%**. GPU hardware minimums remain enforced: RTX PRO 6000
calibration still starts at **30%**, and its fan writer retains that floor.
Zero duty is a command; the RPM column continues to show the measured fan response.
BMC sweep steps wait eight seconds to allow fan response and SDR refresh before sampling.

Original-curve restoration, session ownership, disconnect/lease handling and helper-crash
recovery remain in place. CPU_FAN and CPU_OPT still share one BMC zone. Firmware compatibility
remains restricted to the validated ASUS board and BMC revision.

Update **both app and helper** using `openfan_0.4.3_amd64.deb` from the
[v0.4.3 release](https://github.com/russellmm/openfan-linux/releases/tag/v0.4.3).
Save any open calibration table with OK and exit OpenFan before upgrading; existing tables,
profiles and power settings are preserved. Add new low-duty samples or rerun calibration
after restarting. See [calibration](../fan-calibration.md) and [BMC details](../wrx90-bmc-fans.md).

The full automated suite has **306 passing tests**, including zero-command/readback/restore
coverage for all seven BMC zones, full-range helper-client integration, zero-start calibration
steps and retained RTX PRO 6000 minimum behavior.
