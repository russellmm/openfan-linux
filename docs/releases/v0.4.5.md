# OpenFan Linux v0.4.5

November 14, 2026

The Sensors tab now has a **Use in curves** checkbox beside each sensor. Temperature
sources are opt-in: all checkboxes default unchecked, including in older profiles.
Checking a source lists it in both Home curve cards and the graph editor, using its
saved alias and live reading. Non-temperature rows have disabled checkboxes because
graphs map °C to fan duty. Choices save with the active profile.

Unchecking a source removes it from the menus while preserving any curve already using
it. The closed selector displays **(not listed)** and the existing curve continues using
its assigned sensor. Disconnected sources retain their identity. No existing curve,
calibration, power setting or firmware threshold is rewritten by this selection feature.

Both selectors now use one shared source-selection filter over the same hardware inventory
and published readings used by Sensors. Open graph editors refresh when sources or aliases
change. Listed sources stay live while Home or a graph editor is open, independently of
sensor-table group visibility; active fan curves retain their required readings.

Install `openfan_0.4.5_amd64.deb` from the
[v0.4.5 release](https://github.com/russellmm/openfan-linux/releases/tag/v0.4.5).
Save any open calibration or graph edits and exit OpenFan before upgrading.
See [choosing curve sensors](../curve-sensors.md).

Validation includes **333 passing automated tests** for default/legacy settings, profile
round trips, exact sensor selection, absent sensors and continued polling of assigned
sources after unchecking. Isolated GUI checks exercise both source menus, live changes to
an open graph editor, and preservation of an unchecked assignment when saving its graph.
